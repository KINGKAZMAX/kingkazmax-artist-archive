# 虚拟何为 · 汇报预览

在线入口：https://kingkazmax.github.io/kingkazmax-artist-archive/showcase/

本机入口：作品集根目录的 `作品集总览.html`（可双击）。

- 143项公开预览内容：66网页入口、11份完整时长压缩视频、66张图像。
- 65个公开GitHub仓库默认全部显示；本机HTML另有104个可访问仓库及174份本地视频档案索引。
- 「☆」加入汇报，编辑顺序可拖动排序；排序与收藏只存当前浏览器。
- 点击封面打开独立预览；箭头键切换，Esc关闭。网页独立打开适合设备权限/全屏游戏。
- 「演讲稿 / Script」提供10段提词、计时开始/暂停/重置；Markdown稿位于同目录。
- 手机提词窗口可上下滑动，段落底部可切换。

## 本次验证

桌面首页、搜索筛选、收藏持久化、图片切换、视频关闭后停止、提词与计时已在浏览器验证。用户接管浏览器后停止自动操作；最终变更以JS语法、全部本地资源存在性、公开内容路径审计及上线HTTP校验确认。

LF2网页可打开但游戏资源加载失败，已显示提示。需要API服务的项目保留代码入口。第三方项目保留原作者/开源改编信息；本地私人或归属不明文件未发布公网。
