# Overhead collection / ten portraits / revision 01

User approved the first test style and requested ten images. Produced ten additional square images with the built-in imagegen tool using test-01.png as the shared visual reference. Five female and five male briefs belong to one unified collection.

Visual review: all ten have two open eyes, upward gaze, raised chin, sideways three-quarter head angle, enlarged foreground head and receding torso. Tapered black linework, pale gray ground, angular eyebrows and graphic mouths follow the approved test. Fisheye edge curvature remains restrained, matching the accepted test. New professions, clothes, hair, eye colors and props distinguish characters. Face direction stays mostly consistent with the master.

Files: ten 1254 × 1254 PNGs; review-board.jpg; original PNG ZIP; prompts.md with common and individual briefs. No website publication was requested, so the live gallery remains unchanged.

Figma assets are raster image fills with editable layout, names and labels, not layered vector character drawings. Sync status is tracked separately in docs/figma-sync-manifest.json.
