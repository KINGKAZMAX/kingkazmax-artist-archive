# Frontal portrait direction / V2

Research references: [Ocula artist page](https://ocula.com/artists/aokizy/), [Arario artist profile](https://www.arariogallery.com/artists/375-aokizy/), [K, 2025](https://www.arariogallery.com/ko/artworks/19848-aokizy-k-2025/).

Arario describes a workflow that begins with digitally controlled vector coordinates and translates reproduced visual-media images across physical surfaces. For this project's drawing brief, the directly observed portrait reference suggests these reusable formal choices:

| Feature | Fixed treatment |
| --- | --- |
| Contour | Black silhouette, tapering inner lines, few facial strokes |
| Eyes | Large solid black ovals, off-white sclera, no detailed iris/highlight |
| Hair | A few broad locks, one light colour and one shadow colour |
| Shadows | Crisp boundaries on fringe, cheek, jaw and neck |
| Expression | Slightly raised brows, parted small mouth, surprise mixed with uncertainty |
| View | Level frontal head; both ears visible; no three-quarter rotation |
| Delivery | Complete head/neck silhouette, clear outer margin, true transparent PNG |

This is a first approval sample. Existing character identities, bios, equipment, stories and attributes remain unchanged. Expansion into additional new faces follows direction review. No mass replacement is implied by this sample.
