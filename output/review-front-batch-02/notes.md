# Natural anime batch 02

The user rejected the preceding sculptural hairstyles while batch 01 was still running. That batch was stopped and retained as rejected history. The replacement collection contains twenty individually generated front-facing portraits, ten male and ten female briefs in one unified collection.

Variation now comes from natural anime hair, different facial expressions, eye colors, collar/clothing choices, goggles, earrings and restrained adhesive bandages or minor non-graphic injury marks. The approved contour, simplified feature system and hard cel shadows remain the style reference. Head/neck proportions remain similar.

All twenty outputs are PNG RGBA with transparent pixels in their top margins. These are review candidates, not a production homepage replacement. Exact prompts and reference roles are in prompts.md. Original PNG layers and editable labels are archived on a dedicated Figma Assets page.
