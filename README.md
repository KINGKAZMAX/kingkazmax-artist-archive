# KINGKAZMAX — Images in Motion

A responsive artist archive and local portrait remix experiment, inspired by the restrained structure of museum and gallery artist pages. All portrait artwork shipped here was generated specifically for this project. The portrait lab runs entirely in the visitor's browser; uploaded photographs are not sent to a server.

## Run locally

Open `index.html` in a browser or serve this directory with any static file server.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow that publishes the root directory to GitHub Pages when enabled in repository settings.
